LearnCode це веб-платформа для навчання програмуванню

Опис проєкту
LearnCode  це веб-орієнтована система для навчання програмуванню, розроблена з використанням Django. Платформа поєднує навчальні матеріали, інтерактивні завдання, тестування, елементи гейміфікації та інтеграцію зі штучним інтелектом для генерації задач і перевірки коду.

Основна мета системи це зробити процес навчання програмуванню простим, доступним та ефективним для користувачів, особливо початківців.


• Функціональні можливості

• Користувач
- Реєстрація та авторизація  
- Перегляд курсів і уроків  
- Проходження тестів різних типів  
- Виконання практичних завдань  
- AI-генерація задач  
- Перевірка коду за допомогою AI  
- Перегляд прогресу та статистики  
- Гейміфікація (бали, ліги, досягнення)  

• Адміністратор
- Додавання та редагування курсів  
- Керування уроками  
- Створення тестів і завдань  
- Управління контентом через Django Admin  


• Технології

- Backend: Python, Django  
- Frontend: HTML, CSS, JavaScript  
- База даних: SQLite  
- AI: OpenAI API  
- ORM: Django ORM  



• Інтеграція зі штучним інтелектом

У проєкті використовується OpenAI API для:
- генерації навчальних завдань  
- перевірки коду користувача  
- створення AI-тестів  
- генерації конспектів уроків  
- ведення діалогу (AI-подкаст)  

Вся логіка роботи з AI реалізована у файлі:
courses/ai_service.py


• Інсталяція та запуск

1. Клонувати репозиторій:
`bash
git clone https://github.com/your-username/learncode.git
cd learncode

2. Створити віртуальне середовище:

python -m venv venv
venv\Scripts\activate

3. Встановити залежності:
pip install -r requirements.txt

4. Виконати міграції:
python manage.py migrate

5. Створити суперкористувача:
python manage.py createsuperuser

6. Запустити сервер:
python manage.py runserver

7. Відкрити в браузері:
http://127.0.0.1:8000/


• Налаштування OpenAI
Створіть змінну середовища:
OPENAI_API_KEY=your_api_key

Висновок

Система LearnCode є повноцінною веб-платформою для навчання програмуванню, яка поєднує сучасні технології, інтерактивний підхід та можливості штучного інтелекту. Вона дозволяє користувачам ефективно засвоювати матеріал, практикуватися та відстежувати власний прогрес.
